Hermes ↔ Discord Bot Communication
How your agent and bot talk — two paths, one goal

  ┌──────────────────────┐           pending_jobs.json           ┌──────────────────────┐
  │                      │ ────────►  [JSON array of jobs]  ────────►  │                      │
  │                      │   write               (shared file)         │                      │
  │   Hermes Agent       │           (only one at a time)          │  Job Messenger     │
  │                      │           read + delete after             │  (runJob.ts)         │
  │  job-researcher skill│           removes the file                │                      │
  │                      │                                             │                      │
  └──────────────────────┘                                             └──────────┬───────────┘
                                                                    │
                                                                    │ post to channel
                                                                    ▼
                                                      ┌────────────────────────────┐
                                                      │                          │
                                                      │  Discord channel       │

                                                      │                          │
                                                      └────────────────────────────┘

  └──────────────────────┘                      │                            │

 PATH 3: Bot itself (Direct Discord API)
═══════════════════════════════════════════════════════════════════════

  ┌────────────────────────────┐
  │                            │
  │  Bot's Discord client     │
  │  (discord.js v14)        │
  │                            │
  │  Listens on:               │
  │  • TARGET_CHANNEL_ID       │
  │    → creates threads       │
  │    → calls LOCAL AI        │
  │    → replies to mentions   │
  │                            │
  │  Slash commands:           │
  │  • /notifications          │
  │  • /hermes-status          │
  │                            │
  │  Voice channels:           │
  │  • STATUS_CHANNEL_ID       │
  │    → renames to "running"  │
  │  • NOTIFICATION_CHANNEL_ID │
  │    → renames to "on/off"   │
  │                            │
  └────────────────┬───────────┘
                   │ (Discord WebSocket)
                   ▼
     ┌────────────────────────────────────────────┐
     │                                            │
     │  Discord — your server, all channels      │
     │                                            │
     └────────────────────────────────────────────┘

  ── Key relationship ────────────────────────────────────────────
  • Hermes calls the BOT (via webhook) — it's the SERVER
  • Bot calls DISCORD (via API) — it's the CLIENT
  • Hermes writes to a FILE (pending_jobs.json) — file handoff  ──
